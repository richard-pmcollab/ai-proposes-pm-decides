## The traps

- **Identifying quote:** "Cleanse work all sat on one person **again**" points at one person on a small team. The agent must paraphrase it and still flag it as **recurring**.
- **Overlapping themes:** "ad-hoc requests" and "requests through chat with no priority" are the same theme. The agent should merge them (count 2).
- **Team-suggested actions:** the best actions are already in the *Ideas* column, and the agent should prefer them over inventing its own.
